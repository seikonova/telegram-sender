# Telegram Авторассылка

Десктопное приложение для Windows с графическим интерфейсом: добавление Telegram-аккаунтов и автоматическая рассылка сообщений.

## Возможности

- Добавление нескольких Telegram-аккаунтов (вход по номеру телефона и коду)
- Поддержка двухфакторной аутентификации (2FA)
- **База получателей** — импорт из текста или файла, статусы (ожидает / отправлено / ошибка)
- **Рассылка с нескольких аккаунтов** — два режима: по одному сообщению каждому получателю или с каждого аккаунта каждому
- **Вступление в чаты** — массовый вход в группы/каналы со всех выбранных аккаунтов (исправлено через Telegram API)
- **Парсер ссылок** — извлечение @username и t.me/... из текста или файла
- **Оформление аккаунта** — имя, фамилия, username, описание и фото профиля
- **Папки чатов** — создание папок в Telegram с выбранными чатами на нескольких аккаунтах
- Массовая рассылка с настраиваемой задержкой
- Лог отправки и прогресс-бар
- Хранение сессий локально на компьютере

## Быстрый старт

1. Дважды кликните `start.bat` — скрипт создаст окружение и установит зависимости.
2. Откройте вкладку **Настройки** и укажите **API ID** и **API Hash** с [my.telegram.org](https://my.telegram.org).
3. На вкладке **Аккаунты** добавьте Telegram-аккаунт.
4. На вкладке **База** добавьте получателей (вставьте список или загрузите `.txt` файл).
5. На вкладке **Рассылка** выберите аккаунты, источник «База получателей», введите текст и нажмите **Начать рассылку**.

## Получение API-ключей

1. Перейдите на https://my.telegram.org
2. Войдите под своим номером
3. Откройте **API development tools**
4. Создайте приложение и скопируйте `api_id` и `api_hash`

## Формат получателей

По одному на строку:

- `@username`
- `+79991234567`
- ID чата (число)

## Добавление аккаунта — частые проблемы

1. **Код не приходит в SMS** — Telegram по умолчанию отправляет код в **приложение Telegram** (чат «Telegram»), а не по SMS. Нажмите кнопку **«Через SMS»**, если кода нет в приложении.
2. **Номер телефона** — можно вводить как `+79991234567`, `79991234567` или `89991234567`.
3. **2FA** — если включена двухфакторная защита, сначала введите код, затем пароль 2FA и снова нажмите «Подтвердить».
4. **API ключи** — обязательно заполните вкладку «Настройки» до добавления аккаунта.

## Важно

- Используйте рассылку только для легитимных целей и с согласия получателей.
- Слишком частая отправка может привести к ограничениям со стороны Telegram (FloodWait).
- Рекомендуемая задержка между сообщениями: **5–15 секунд**.
